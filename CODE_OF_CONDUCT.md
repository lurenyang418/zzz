# Code of Conduct

## Our standard

We want zzz to be a welcoming and constructive project. Participants are expected to:

- communicate respectfully and assume good faith;
- focus on ideas and evidence rather than people;
- welcome different backgrounds and viewpoints;
- accept constructive feedback; and
- avoid harassment, discrimination, personal attacks, and deliberately disruptive behavior.

## Enforcement

Project maintainers may remove or edit comments, close discussions, or restrict participation when conduct violates this standard. Report concerns privately through the contact methods described in [SECURITY.md](SECURITY.md); do not include sensitive vulnerability details in a public issue.

This code of conduct applies to project spaces and to interactions representing the project.
