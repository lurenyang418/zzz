# Security Policy

## Supported versions

Only the latest `main` branch and the latest published release receive security fixes.

## Reporting a vulnerability

Please use [GitHub's private vulnerability reporting](https://github.com/lurenyang418/zzz/security/advisories/new) or contact the repository maintainers privately through GitHub. Do not open a public issue for an unpatched vulnerability.

Include, when safe to share:

- the affected version or commit;
- a clear description of the impact;
- reproduction steps or a minimal proof of concept; and
- any suggested mitigation.

Please avoid including Tokens, private repository data, or other credentials in a report. We will acknowledge the report when possible, investigate it, and coordinate disclosure after a fix is available.
